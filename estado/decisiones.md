# Registro de decisiones

Una entrada por decisión relevante, con el formato siguiente. En la revisión semanal se completan "Resultado real" y "Aprendizaje". Las entradas no se borran.

```
## DEC-### · AAAA-MM-DD · título
- Decidió: Directora / Comité / CEO (APR-###)
- Decisión:
- Alternativas descartadas y por qué:
- Resultado esperado y plazo:
- Disenso (quién y qué sostiene):
- Resultado real:
- Aprendizaje:
```
